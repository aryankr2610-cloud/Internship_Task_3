#  Data Analytics & Business Intelligence Project (Task-3)

## 🔍 Project Overview

This project focuses on performing **advanced data analysis and business intelligence reporting** using a sales dataset. The objective is to extract meaningful insights from raw data using tools like **SQL, Excel, and Power BI**, and support decision-making through data-driven strategies.


## 🎯 Objectives

* Analyze business performance using KPIs
* Identify trends in sales, profit, and growth
* Evaluate regional and category performance
* Understand the impact of discounts on profitability
* Provide strategic recommendations for business improvement


## 🛠 Tools & Technologies Used

* **SQL** – Data querying and analysis (CASE, HAVING, Subqueries)
* **Microsoft Excel** – Data cleaning, variance, growth %, and charts
* **Power BI** – Interactive dashboard and KPI visualization


## 📁 Dataset Description

The dataset contains transactional sales data with the following key attributes:

* Order Date
* Region
* Category & Sub-Category
* Sales & Profit
* Quantity
* Customer Segment
* Discount


## ⚙️ Data Processing & Analysis

### 🔹 SQL Analysis

* Used **CASE statements** to categorize profit levels
* Applied **HAVING clause** to filter high-performing regions
* Used **subqueries** to identify above-average sales products


### 🔹 Excel Analysis

* Calculated **Variance** (Total Sales - Actual Sales)
* Computed **Growth %** for sales trend analysis
* Created **Profit Status (Profit/Loss)**
* Built visual charts:

  * Sales by Region
  * Category Distribution
  * Sales Trend over Time


### 🔹 Power BI Dashboard

An interactive dashboard was developed including:

* 📌 KPI Cards:

  * Total Sales
  * Total Profit

* 📊 Visualizations:

  * Bar Chart → Sales by Region
  * Pie Chart → Sales by Category
  * Line Chart → Sales Over Time

* 🎛 Filters (Slicers):

  * Region
  * Category
  * Profit Category


## 📈 Key Insights

* The company shows **inconsistent month-over-month growth**
* Certain regions are **underperforming in sales and profit**
* The **Technology category drives the highest growth**
* High discounts are **negatively impacting profit margins**
* The **Consumer segment contributes the highest revenue**


## 💡 Business Recommendations

* Improve performance in underperforming regions through targeted strategies
* Reduce excessive discounting to maintain profitability
* Invest more in high-growth categories like Technology
* Focus on customer retention in the Consumer segment
* Implement better demand forecasting for stable growth


## 📌 Conclusion

This project demonstrates how data analytics tools can be used to transform raw data into actionable business insights. By leveraging SQL, Excel, and Power BI, the analysis provides a comprehensive understanding of business performance and supports strategic decision-making.
